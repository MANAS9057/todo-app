# To-Do App

A full stack task manager built with Node.js, Express.js and MongoDB.

## Features
- Add, view, update and delete tasks (CRUD)
- EJS views for the frontend
- MongoDB for data storage

## Tech Stack
Node.js, Express.js, MongoDB, EJS, HTML, CSS, JavaScript

## Run Locally
1. Install and start MongoDB on localhost:27017
2. `npm install`
3. `node index.js`
